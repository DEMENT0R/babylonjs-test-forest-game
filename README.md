# Тихая поляна

Прогулка по лесной поляне от третьего лица на Babylon.js: три героя (волк, лиса, олень),
шестнадцать кристаллов, три режима камеры, пресеты графики, синтезированные звуки
шагов, ветра и птиц.

## Запуск

```bash
npm install
npm run dev        # дев-сервер Vite, http://localhost:5173
npm run build      # проверка типов + сборка в dist/
npm run preview    # посмотреть собранную версию
```

## Структура

```
index.html              разметка UI (меню, выбор героя, HUD, панель настроек)
styles.css              все стили
src/
  main.ts               инициализация, состояния меню / выбор / игра, клавиатура, игровой цикл
  heroes.ts             описания героев, загрузка GLB, смешивание анимаций
  world.ts              поляна, деревья, камни, платформы, кристаллы; запросы для физики
  player.ts             ввод (клавиатура, сенсорный стик), движение, прыжок, коллизии
  camera.ts             три режима камеры, захват курсора, облёт за меню
  settings.ts           пресеты, localStorage, тени и пост-обработка для каждой сцены
  audio.ts              звук на Web Audio API: ветер, птицы, шаги и приземления
  utils.ts              мелкие помощники
  ui/
    menu.ts             главное меню
    select.ts           экран выбора героя (3D-подиумы и карточки)
    settings-panel.ts   панель настроек
    hud.ts              счёт, подсказки, FPS, кнопка камеры
public/models/          wolf.glb, fox.glb, stag.glb
CREDITS.md              лицензии моделей и шрифтов
```

Модели лежат обычными файлами в `public/models/` и грузятся по URL
(`import.meta.env.BASE_URL + 'models/…'`). Сборка использует `base: './'`,
поэтому `dist/` можно выложить в любую подпапку, например на GitHub Pages.

## Как добавить героя

1. Положите `имя.glb` в `public/models/` и допишите лицензию в `CREDITS.md`.
2. Добавьте запись в `HEROES` в `src/heroes.ts`: имена анимаций, исходную высоту модели (`srcH`),
   скорости и прыжок.
3. В `src/ui/select.ts` добавьте позицию подиума в `SLOT_X`, а в `styles.css` поправьте
   число колонок у `.cards`.
