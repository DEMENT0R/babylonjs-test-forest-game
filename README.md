# Тихая поляна

Прогулка по лесным полянам от третьего лица на Babylon.js: три героя (волк, лиса, олень),
сгенерированные уровни с кристаллами и порталом, биомы со своей атмосферой (летний лес,
осенняя роща, каменное плато, зимний лес со снегопадом, ночной лес со светлячками, озёрный край), три режима камеры, пресеты
графики, трава, которая качается на ветру и приминается героем, синтезированные звуки
шагов, ветра и птиц.

Разработка — [Максим Безрукавников](https://github.com/DEMENT0R), при участии Claude (Anthropic).

## Запуск

```bash
npm install
npm run dev        # дев-сервер Vite, http://localhost:5173
npm run build      # проверка типов + сборка в dist/
npm run preview    # посмотреть собранную версию
```

Модели лежат обычными файлами в `public/models/` и грузятся по URL
(`import.meta.env.BASE_URL + 'models/…'`). Сборка использует `base: './'`,
поэтому `dist/` можно выложить в любую подпапку, например на GitHub Pages.

## Уровни

Уровень строится из **рецепта** (`levels/recipes.ts`): биом, размер, число кристаллов,
цепочек платформ и полян, доля спрятанных кристаллов. Первые восемь рецептов заданы вручную,
дальше параметры растут до потолка, а биом выбирается по сиду. Один номер уровня — всегда
одна и та же раскладка.

Генератор (`levels/generator.ts`) расставляет поляны, цепочки ступеней (подъём не больше
1.25 м и зазор не больше 2.4 м — под прыжок волка, самого слабого прыгуна), лес по
Poisson-диску с рощами по шуму и сплошной стеной по краю, камни и кристаллы. Затем поиском
в ширину по сетке 0.5 м проверяет, что до каждого кристалла и каждой цепочки можно дойти;
если нет — пробует другой поток случайных чисел.

Рельеф (`levels/terrain.ts`) — фрактальный шум с параметрами биома (у каменного плато —
острые гребни) и валом за границей уровня. Центральная поляна, боковые поляны и площадки под
цепочками платформ выравниваются с плавным переходом. Высота запекается в сетку 1 м; по ней
же строится сетка земли (шаг 1.5 м). Первые уровни почти плоские — множитель `relief` в рецепте.
Склон круче 38° (`MAX_WALK_SLOPE`) не пускает героя вверх, а на таком склоне он съезжает;
генератор считает такие клетки стенами при проверке достижимости.

Портал в каменном круге открывается после 80% кристаллов, все кристаллы дают звезду.
В меню «Уровни» — открытые уровни с лучшим временем.

В dev-сборке в консоли браузера доступен `__game` (`world`, `player`, `rig`, `beginLevel(n)`).

## Как добавить биом

Добавьте запись в `BIOMES` (`levels/biomes.ts`) и используйте её id в рецептах.
У биома есть звуковая атмосфера (`ambience`: частота птиц, кукушка, сверчки, совы, сила
ветра), поверхность для шагов (`surface`: трава или снег), частицы в воздухе (`particles`)
и ночной свет от кристаллов (`crystalLights`: два ближайших к герою кристалла освещают округу —
вместе с небом и луной это предел в 4 источника у материалов по умолчанию) и вода
(`water`: низины рельефа и прокопанные озёра; уровень воды подбирается так, чтобы
естественные низины занимали не больше 6% карты). Мелкая вода замедляет героя и ослабляет
прыжок, глубже 0.9 м (`MAX_WADE_DEPTH`) не зайти — для генератора это стена.
Тип деревьев — `pine` или `birch`; новый тип рисуется в `Level.buildTrees`.

## Как добавить героя

1. Положите `имя.glb` в `public/models/` и допишите лицензию в `CREDITS.md`.
2. Добавьте запись в `HEROES` в `src/heroes.ts`: имена анимаций, исходную высоту модели (`srcH`),
   скорости и прыжок.
3. В `src/ui/select.ts` добавьте позицию подиума в `SLOT_X`, а в `styles.css` поправьте
   число колонок у `.cards`.
